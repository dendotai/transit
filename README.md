# Transit

Drop a game folder into a window on your computer, and it shows up in your Steam Deck's library as a game: files in place, artwork set, Proton chosen, ready to play in Game Mode.

Transit is for the games you own outside Steam: old CD games, games from closed stores, DRM-free copies.

## Parts

- **Decky plugin:** runs on the Steam Deck under Decky Loader. It makes the Deck visible on the local network, receives the files, puts each game in its own folder, and adds it to the Steam library with artwork.
- **Companion app:** runs on your computer. It finds the Deck on the network and sends the game folders you drop into its window.
