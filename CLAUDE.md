## Commits

Every commit message takes a conventional prefix (`feat:`, `fix:`, `chore:`, …). `dev` is the default branch; nothing is committed to `main` directly.

## Issue tracker

Issues live in this repo's GitHub Issues (`gh` CLI), with the triage and state labels from Stack; `.github/workflows/maintenance.yml` strips state labels on close.

## Names

The product name is Transit. "Steam" and "Steam Deck" appear only in descriptions ("for Steam Deck"), never in a product, plugin or app name, because Valve owns those names.
